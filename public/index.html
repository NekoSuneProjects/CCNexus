INSTALLER

Connect CraftOS

  1. Create a pairing codeUse the Pair Device button in this dashboard.
  2. Run the installer in CC:Tweakedwget run https://your-domain/install.lua
  3. Enter your dashboard URL + codeThe installer saves its own device token and starts automatically on reboot.

DEPLOYMENT

Docker or standalone

docker compose up -d

Persist /app/data. Set CCNEXUS_PUBLIC_URL when running behind a reverse proxy and CCNEXUS_ADMIN_TOKEN for a fixed admin credential.

For YouTube playback, the host needs yt-dlp and FFmpeg. The provided Docker image includes both.
