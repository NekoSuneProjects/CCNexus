HOW ISOLATION WORKS

One Nexus, many Minecraft instances

A pairing code belongs to exactly one workspace. Device IDs, turtles, speakers, ME storage and telemetry stay grouped under that workspace.

●Online worldFull real-time control
◌Offline worldLast telemetry stays searchable
◇Single playerReconnects when the save opens
▦Dedicated serverIndependent CC fleet
Commands cannot execute while Minecraft/CC:Tweaked is offline. CCNexus keeps the last known data so you can still inspect the workspace.

INSTALLER

Connect CraftOS

  1. Select or create a Server/WorldThe workspace picker decides where the new device belongs.
  2. Create a pairing codeCodes are single-use and expire after 10 minutes.
  3. Run the installerwget run https://your-domain/install.lua
  4. Enter domain + codeThe installer learns the workspace automatically.
