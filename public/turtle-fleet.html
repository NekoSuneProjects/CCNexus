Fleet nodes

Shared stations / waypoints

Physically place the selected turtle at the exact block where it should stand. For a chest, put the turtle directly above it and use interaction side down.

Known stations

Shared fuel depot

All Fleet turtles can automatically visit the same fuel-only chest before they run too low. Slot 16 is reserved for fuel by default.

CCNexus does not create fuel from nothing: the depot chest must contain valid turtle fuel. You can keep that chest restocked manually or with your modpack's automation.

Quarry → Base delivery turtle

A courier repeatedly visits the quarry chest, loads cargo, carries it to the base chest, unloads, and refuels from the shared depot when needed.

Crop turtle

Navigates to the crop waypoint, scans the grid below itself, harvests mature vanilla crops, replants from the seed slot, and can unload harvests at base.

Tree patrol turtle

Patrols a grid, checks all four sides at each patrol cell for vanilla logs, chops the trunk upward, returns to the same block, and replants a sapling.

Direct quarry

Uses the selected turtle's current position as the quarry start. Underground GPS dropouts are covered by dead reckoning after the turtle has calibrated its heading.
